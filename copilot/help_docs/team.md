# Team: phlebos, runners, users, patients

## Phlebo list / add a phlebo
link: /phlebos/list
keywords: phlebo, phlebotomist, add phlebo, new phlebo, team directory, staff, edit phlebo
Open **Phlebos › Team Directory**. Use **Add** to create a phlebo; open a row to edit details,
serving cities/areas and login.

## Phlebo shift rosters
link: /phlebos/rosters
keywords: roster, shift, working hours, phlebo timing, availability, week off
**Phlebos › Shift Rosters** sets each phlebo's working days and hours. Phlebos without a roster are not
offered for assignment.

## Phlebo leave management
link: /phlebos/leaves
keywords: leave, phlebo leave, holiday, absent, off day
**Phlebos › Leave Management** to add or approve phlebo leaves.

## Phlebo travel / distance report
link: /phlebos/distance-reports
keywords: travel report, distance, km, mileage, travel allowance
**Phlebos › Travel Report** shows the distance travelled per phlebo.

## Phlebo live tracking
link: /phlebos/live-view
keywords: live tracking, phlebo tracking, route, map
**Phlebos › Live Tracking** shows phlebos and their routes on the map.

## Phlebo performance / reviews
link: /reviews/phlebos
keywords: review, rating, feedback, performance
**Performance › Staff Reviews** shows patient ratings and feedback for phlebos.

## Attendance report
link: /attendance-report
keywords: attendance, check in, check out, present
**Attendance** in the left menu shows phlebo check-in/check-out.

## Runners and runner tasks
link: /runner/list
keywords: runner, sample pickup, runner task, tour, route template
**Runners › Runner Directory** for runners; **Task Management** for pickup tasks;
**Route Templates** for fixed tours.

## Patients
link: /customers
keywords: patient, patient list, add patient, patient history
**Patients** in the left menu lists patients and their past orders.

## Users (CRM logins)
link: /users
keywords: user, add user, login, staff login, password, user management
**User Management** in the left menu adds CRM users and sets their role.

## Roles and permissions
link: /settings/role
keywords: role, permission, access, rights, cannot see menu, menu missing
**Administration › Roles & Permissions**. If a user cannot see a menu or button, their role lacks that
permission - an admin can enable it here.
