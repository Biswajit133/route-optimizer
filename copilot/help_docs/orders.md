# Orders

## Orders list (see, search and filter orders)
link: /orders
keywords: orders, order list, all orders, search order, filter, today orders, status, export, download excel
Open **Orders** from the left menu. The list shows every order (visit) you are allowed to see.
- Use the date, status, slot, phlebo and city filters at the top to narrow the list.
- Search by patient name, phone or order number.
- Click an order to open its full view.
- Export (Excel) is in the actions menu at the top of the list, when your role has it.

## Add / create a new order
link: /orders/create
keywords: create order, new order, add order, book order, booking, new booking, home collection
1. Open **Orders** and click **Add order** (or go to the link).
2. Pick or add the patient, address and city.
3. Add the tests, choose the date and slot.
4. Check price, discount/coupon and payment type, then save.
The phlebo is assigned automatically if auto-assign is on for your lab; otherwise assign from the order list.

## Open an order and see its details
link: /orders
keywords: order details, view order, order status, track order, timeline, patient details, order history
Open **Orders**, find the order (search by number, name or phone) and click it. The order view shows
patients, tests, slot, phlebo, payment and the full status history. You can also ask me
"status of order <number>".

## Reschedule, cancel or edit an order
link: /orders
keywords: reschedule, cancel order, edit order, change slot, change date, change test, modify order
Open the order from **Orders**. The actions on the order (edit, reschedule, cancel) are shown there,
depending on your role permissions. Cancel and reschedule ask for a reason; the reason lists are managed
in **Administration › Visit Reasons**.

## Import orders from Excel / CSV
link: /orders/import-v2
keywords: import, bulk order, upload orders, excel, csv, sheet, bulk upload
Open **Orders › Import**. Download the sample file, fill it, upload and check the preview before importing.
The Import option is shown only when order import is enabled for your account.

## Batch assign phlebos
link: /orders/batch-assign
keywords: assign phlebo, batch assign, bulk assign, auto assign, assign many orders
Use **Orders › Batch assign** to assign phlebos to many orders at once (shown when batch assign is enabled
for your account). Single orders can be assigned from the order list.

## Schedule / calendar view
link: /calendar-view
keywords: calendar, schedule, day view, slot wise, planner
**Schedule** in the left menu shows orders on a calendar by day and slot.

## Live location of phlebos
link: /live-location
keywords: live location, track phlebo, where is phlebo, map, gps
**Live Location** in the left menu shows phlebos on the map in real time.
